# ChestnutOne 本地管理后台

本次实现把现有“邀请码”作为管理对象，不是短信一次性验证码。它们仍用于 Web/小程序开始会议前的验证。

## 启动与首次使用

Windows 项目根目录：

```powershell
.\.venv\Scripts\python.exe scripts/start_admin_local.py
```

macOS / Linux：

```bash
.venv/bin/python scripts/start_admin_local.py
```

打开 `http://127.0.0.1:8080/admin`，首次设置一个 12–200 字符的管理员密码。管理员身份和客户邀请码分开，管理员登录不授予会议访问权限。密码以带随机盐的 PBKDF2-SHA256 摘要保存，管理员登录会话有效期 8 小时。退出会使该会话立即失效；连续输错 5 次后需等待 10 分钟。

默认端口被占用时，设置 `CHESTNUT_LOCAL_ADMIN_PORT=8081` 后再执行启动器。启动器仅绑定 `127.0.0.1`。本地翻译需要在项目根目录 `.env` 中填写 `DASHSCOPE_API_KEY` 和 `BAILIAN_API_HOST`；启动服务时自动读取这两项，已有非空环境变量优先，修改后需重启。不会从 `.env` 加载 COS 或其他设置。直接运行 `server.py` 也会读取这两项，只有显式设置 `CHESTNUT_ADMIN_ENABLED=1` 才启用后台。凭证缺失或百炼返回 401/403 时，客户端暂停收音并保留具体错误，不再无限重试；修正配置并重启服务后可点击 Reconnect。

后台页面、接口只接受直接的 loopback 连接和本机 Host；转发头、云网关头、局域网来源被拒绝。后台会话采用独立 HttpOnly Cookie；写操作同时校验同源 Origin 和 CSRF 凭证。无需也不应该把本地管理入口发布到公网。

## 邀请码管理

- **生成**：客户标签必填；一次生成 1–100 个独立随机码。新生成码为 6 位数字（首位不为 0），例如 `482719`。用安全随机数生成并在事务内查重；包括停用/过期码在内的历史码均不复用。已有长码保持有效。继续沿用验证限流和异常提示。
- **展示和分发**：生成完成后可以复制单个或整批；列表默认隐藏明文，只显示尾号。通过“查看”显示完整码，再点“隐藏”收起。明文查看会记录管理活动。
- **配置**：可指定备注、截至某时刻的有效期（输入按北京时间解释）、每码成功验证次数上限。可一键选择 1 小时、4 小时、12 小时、24 小时、7 天、长期；快捷时长从服务端实际生成时开始计算。手动调整日期即切换为自定义。有效期留空表示长期有效，次数上限 0 表示不限。
- **额度口径**：每次成功提交邀请码计 1 次，按数据库事务检查并扣减；有效凭证内开始会议、网络重连不再扣次。次数用完后已有凭证仍有效；到期或停用则撤销访问。
- **停用/恢复**：停用后不能再次验证，已有凭证失效，正在使用该码的会议连接会被关闭。恢复需要客户重新验证，不会复活旧凭证；原有效期和剩余额度依然适用。
- **搜索和记录**：按标签、完整码或备注搜索；按可用、停用、过期、额度用完筛选。支持按生成时间新到旧/旧到新、失效时间近到远/远到近排序；失效排序中长期码始终放最后。可使用的码剩余 24 小时内标黄、1 小时内标橙，过期或停用码不显示临近过期提示。每码可以查看验证、会议接入、存稿和管理操作记录。同标签的一组码用尾号和独立 ID 区分。

停用或到期时，当前会议可能因凭证失效无法保存。原有客户端会保留未保存内容并提供重试；客户需使用有效码重新验证后重试。不要在保存成功前刷新 Web 或彻底退出小程序。

启用本地后台时，`CHESTNUT_WEB_INVITE_CODES` 中已有的码会按码值去重导入；导入后可在后台停用，重启不会自动重新启用。配置文件中删除旧码不会删除数据库记录，请在后台停用。切换到数据库管理后，旧版未绑定码 ID 的凭证需重新验证。

## 访问与使用统计

界面支持今天、近 7 天及最近 90 天内的自定义日期范围，统一按北京时间划日。码的累计成功验证次数永久保留；活动、失败次数和使用客户端统计基于最近 90 天的记录。

| 指标 | 实际口径 |
| --- | --- |
| 服务页访问 | Web 每次加载首页 / 小程序每次展示 Setup，成功上报一次计一次 |
| 访问客户端 | 所选范围内对匿名客户端标识去重，不等于真实人数 |
| 成功验证 | 输入有效邀请码并成功签发凭证的次数 |
| 失败 / 限流 | 邀请码验证失败与被限流的请求数；未成功解析的请求不计入验证失败 |
| 会议接入 | 通过鉴权、语言参数和并发检查后的 WebSocket 接入；同客户端同会议重连去重，不等于模型翻译成功 |
| 按码使用 | 所选范围内每个码的成功/失败验证、成功验证客户端数、会议接入数 |

Web 客户端 ID 保存在本地存储中；微信云通道用 OpenID，局域网小程序用本地客户端 ID。清除存储、更换浏览器可能被算作新客户端。每日去重数的加总可能大于整个范围去重数。匿名访问在客户输入码之前无法归属于某个码；输错的未知码也无法归属于某个客户。

访问上报失败不会阻塞会议。记录仅在开启本地后台的实例产生，不会读取线上云托管的历史数据。当前小程序默认仍连接原有云环境；验证本地小程序统计时，在开发者工具实验配置中将 `CLOUD_ENV_ID` 留空以连接本地服务。此次实现没有切换小程序的默认云环境。

## 异常提示

以下规则自动产生提示，并列出发生时间、数量、相关码/网络匿名标识：

| 规则 | 触发条件 |
| --- | --- |
| 连续验证失败 | 同一网络来源滚动 10 分钟内 ≥ 5 次邀请码验证失败 |
| 同一码多人使用 | 同一码滚动 24 小时内 ≥ 5 个匿名客户端成功验证 |
| 不可用码被反复尝试 | 同一码滚动 10 分钟内 ≥ 3 次停用、过期或额度用完后的尝试 |
| 频繁触发验证限流 | 同一网络来源滚动 10 分钟内 ≥ 3 次被验证接口限流 |
| 管理员连续输错密码 | 同一网络来源滚动 10 分钟内 ≥ 3 次管理员登录失败 |

提示是核实线索，不是违规判定，不会自动封禁。相同规则、来源和固定规则时间段内合并展示，命中次数是满足规则的触发次数；提示正文中的次数是滚动窗口内的实际数量。标记“已核实”后，后续再次触发会重新变成“待核实”。规则阈值目前固定，后续可根据私测数据调整。

## 本地数据与边界

- 数据库：`data/admin.sqlite3`，可由 `CHESTNUT_ADMIN_DB` 指定其他路径。包含邀请码明文、管理员密码摘要、会话、访问与活动记录；本机文件访问权限应按含凭证文件对待。
- 数据库开启 WAL。备份时先停止服务，再备份整个 `data/` 目录；不要在运行中只复制主数据库文件。服务启动及运行中每小时清理超过最近 90 个北京时间自然日的活动、访问汇总和提示，以及已过期管理员会话。邀请码、已用额度、管理员密码和签名密钥不清理；SQLite 释放的页面会复用，数据库文件不一定立即变小。
- `.gitignore` 和 `.dockerignore` 排除了 `data/`、日志与测试截图，避免把本地邀请码或运行记录带到远端/镜像。
- 事件不存原始 IP、原始客户端 ID、错误邀请码正文、语音或字幕内容；匿名标识使用本地密钥 HMAC。邀请码明文只通过管理员生成或显式查看接口返回。
- 本地限流、并发登记仍沿用单实例设计。SQLite 是本地实验的持久层，不是横向扩容方案。
- 不含管理账号多人协作、角色分权、密码找回、在线服务发布或线上统计同步。

## 活动精简与旧库迁移

- 同一客户端、同一码、同一场会议当天的接入/重连合并成一条，保留首次时间、最近时间和接入次数，不再单独写“连接结束”事件。跨天接入分别统计。
- 服务页访问按“日期 + 匿名客户端 + 渠道”累加到日汇总，不逐次写活动明细；访问次数和去重客户端仍可在“访问与用码”查看。
- 同一码 10 分钟内反复查看/复制明文合并记录，并保留次数。验证失败、停用/恢复等关键事件保持明细，异常规则的滚动窗口判断不变。
- 详细活动和日汇总保留最近 90 天，页面不再提供已清理日期的查询。当前 90 天内的访问、验证与会议统计不因精简而丢失。
- 首次升级旧库前，使用 SQLite backup API（包含 WAL 中已提交内容）生成同目录 `admin.sqlite3.before-activity-v1.bak`。之后把旧访问转为日汇总、合并重复会议接入，并移除冗余的结束记录。整个数据转换在事务中执行，重复启动不会重复累计。
- 迁移备份保留，不自动覆盖。备份也包含凭证，应同样保存在受保护的本地 `data/` 目录。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
node --test tests/test_access.cjs tests/test_languages.cjs
```

真实浏览器自动验收（开发依赖，不加到服务器运行依赖中）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe scripts/verify_admin_browser.py
```

浏览器脚本使用机器上安装的 Chrome/Edge，也可用 `CHESTNUT_TEST_BROWSER` 指向 Chromium 可执行文件。测试创建独立临时数据库，验证首次设置、批量生成、明文和复制、Web 邀请码入口、停用/恢复、统计与异常、搜索、移动宽度布局和会话恢复。截图和 JSON 结果写到 `test-results/admin/`。它使用虚拟麦克风，不调用付费模型、不写 COS、不污染正式本地后台。
